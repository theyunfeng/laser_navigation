# 4. 路径段模块

本章详细介绍路径段模块的设计与实现。

## 4.1 模块概述

路径段模块采用面向对象的多态设计，通过抽象基类 `PathSegment` 定义统一接口，不同类型的路径段（直线、贝塞尔曲线、圆弧等）继承该基类并实现各自的具体逻辑。

```
┌─────────────────────────────────────────────────┐
│                PathSegment (抽象基类)            │
│  + getType(): PathSegmentType                   │
│  + getTotalLength(): double                     │
│  + getStartPose(): Pose2D                       │
│  + getEndPose(): Pose2D                         │
│  + getStartHeading(): double                    │
│  + getEndHeading(): double                      │
│  + getRemainingDistance(pose): double           │
│  + isReached(pose, threshold): bool             │
│  + getLateralDeviation(pose): double            │
│  + getConstraints(): MotionConstraints          │
└────────────────────┬────────────────────────────┘
                     │
     ┌───────────────┼───────────────┐
     │               │               │
     ▼               ▼               ▼
┌─────────┐   ┌─────────────┐   ┌───────────┐
│Straight │   │   Bezier    │   │    Arc    │
│ Segment │   │   Segment   │   │  Segment  │
└─────────┘   └─────────────┘   └───────────┘
                                      │
                              ┌───────┴───────┐
                              │               │
                        createDubins()  createReedsShepp()
```

## 4.2 PathSegment 基类

### 4.2.1 接口定义

```cpp
class PathSegment {
public:
    virtual ~PathSegment() = default;

    // 基本属性查询
    virtual PathSegmentType getType() const = 0;
    virtual double getTotalLength() const = 0;
    virtual Pose2D getStartPose() const = 0;
    virtual Pose2D getEndPose() const = 0;
    virtual double getStartHeading() const = 0;
    virtual double getEndHeading() const = 0;

    // 距离和状态查询
    virtual double getRemainingDistance(const Pose2D& current_pose) const = 0;
    virtual bool isReached(const Pose2D& current_pose, double threshold) const = 0;
    virtual double getLateralDeviation(const Pose2D& current_pose) const = 0;

    // 约束参数
    const MotionConstraints& getConstraints() const;
    void setConstraints(const MotionConstraints& constraints);
    bool isForward() const;

protected:
    MotionConstraints constraints_;
};

using PathSegmentPtr = std::shared_ptr<PathSegment>;
```

### 4.2.2 接口说明

| 方法 | 描述 | 用途 |
|-----|------|------|
| `getType()` | 返回路径段类型 | 用于类型判断和动态转换 |
| `getTotalLength()` | 返回路径总长度 | 速度规划初始化 |
| `getStartPose()` | 返回起点位姿 | 路径连接、初始化 |
| `getEndPose()` | 返回终点位姿 | 到达判断、下一段衔接 |
| `getStartHeading()` | 返回起始航向 | 旋转规划 |
| `getEndHeading()` | 返回终止航向 | 终点旋转规划 |
| `getRemainingDistance()` | 计算剩余距离 | 速度规划、到达判断 |
| `isReached()` | 判断是否到达 | 段切换 |
| `getLateralDeviation()` | 计算横向偏差 | 偏离检测、重规划触发 |

## 4.3 StraightSegment 直线段

### 4.3.1 类定义

```cpp
class StraightSegment : public PathSegment {
public:
    StraightSegment(const Pose2D& start, const Pose2D& end,
                    const MotionConstraints& constraints);

    // PathSegment接口实现
    PathSegmentType getType() const override { return PathSegmentType::kStraight; }
    double getTotalLength() const override;
    Pose2D getStartPose() const override;
    Pose2D getEndPose() const override;
    double getStartHeading() const override;
    double getEndHeading() const override;
    double getRemainingDistance(const Pose2D& current_pose) const override;
    bool isReached(const Pose2D& current_pose, double threshold) const override;
    double getLateralDeviation(const Pose2D& current_pose) const override;

    // 直线特有方法
    bool getLineParameters(double& k, double& b) const;  // 获取直线方程参数
    bool isVertical() const;  // 是否为垂直线

private:
    Pose2D start_;
    Pose2D end_;
    double length_;
    double heading_;
    double k_, b_;      // 直线方程 y = kx + b
    bool is_vertical_;  // 是否垂直
};
```

### 4.3.2 实现细节

**直线方程计算**：
```cpp
// 垂直线判断
if (std::abs(dx) < 1e-6) {
    is_vertical_ = true;
} else {
    k_ = dy / dx;
    b_ = start_.y - k_ * start_.x;
}
```

**剩余距离计算**：
```cpp
double StraightSegment::getRemainingDistance(const Pose2D& pose) const {
    // 计算在直线上的投影点
    double dx = end_.x - start_.x;
    double dy = end_.y - start_.y;
    double t = ((pose.x - start_.x) * dx + (pose.y - start_.y) * dy) 
               / (length_ * length_);
    t = std::max(0.0, std::min(1.0, t));
    
    // 剩余距离
    return (1.0 - t) * length_;
}
```

**横向偏差计算**：
```cpp
double StraightSegment::getLateralDeviation(const Pose2D& pose) const {
    if (is_vertical_) {
        return std::abs(pose.x - start_.x);
    }
    // 点到直线的距离公式
    return std::abs(k_ * pose.x - pose.y + b_) / std::sqrt(k_ * k_ + 1);
}
```

### 4.4.2 三次贝塞尔曲线公式

三次贝塞尔曲线的参数方程：

$$B(t) = (1-t)^3 P_0 + 3(1-t)^2 t P_1 + 3(1-t) t^2 P_2 + t^3 P_3$$

其中 $t \in [0, 1]$，$P_0$ 为起点，$P_3$ 为终点，$P_1, P_2$ 为控制点。

**一阶导数（切线）**：

$$B'(t) = 3(1-t)^2(P_1 - P_0) + 6(1-t)t(P_2 - P_1) + 3t^2(P_3 - P_2)$$

**二阶导数**：

$$B''(t) = 6(1-t)(P_2 - 2P_1 + P_0) + 6t(P_3 - 2P_2 + P_1)$$

### 4.4.3 弧长-参数映射

由于贝塞尔曲线的弧长没有解析解，采用数值方法预计算弧长表：

```cpp
void BezierSegment::computeArcLengthTable() {
    t_table_.resize(kTableResolution + 1);
    arc_length_table_.resize(kTableResolution + 1);
    
    t_table_[0] = 0.0;
    arc_length_table_[0] = 0.0;
    
    Eigen::Vector2d prev_point = control_points_[0];
    double cumulative_length = 0.0;
    
    for (int i = 1; i <= kTableResolution; ++i) {
        double t = static_cast<double>(i) / kTableResolution;
        Eigen::Vector2d point = getPointAtParameter(t);
        cumulative_length += (point - prev_point).norm();
        
        t_table_[i] = t;
        arc_length_table_[i] = cumulative_length;
        prev_point = point;
    }
    
    total_length_ = cumulative_length;
}
```

**弧长到参数的查找**：
```cpp
double BezierSegment::getParameterAtArcLength(double arc_length) const {
    // 二分查找
    auto it = std::lower_bound(arc_length_table_.begin(), 
                                arc_length_table_.end(), arc_length);
    size_t idx = std::distance(arc_length_table_.begin(), it);
    
    if (idx == 0) return 0.0;
    if (idx >= arc_length_table_.size()) return 1.0;
    
    // 线性插值
    double ratio = (arc_length - arc_length_table_[idx-1]) / 
                   (arc_length_table_[idx] - arc_length_table_[idx-1]);
    return t_table_[idx-1] + ratio * (t_table_[idx] - t_table_[idx-1]);
}
```

### 4.5.2 三点确定圆弧

通过三点（起点、中间控制点、终点）确定圆弧，使用外接圆公式计算圆心：

```cpp
std::unique_ptr<ArcSegment> ArcSegment::createFromThreePoints(
    const Pose2D& start, const Pose2D& mid_point, const Pose2D& end) {
    
    double x1 = start.x, y1 = start.y;
    double x2 = mid_point.x, y2 = mid_point.y;
    double x3 = end.x, y3 = end.y;
    
    // 计算行列式 D = 2 * | x1-x3  y1-y3 |
    //                    | x2-x3  y2-y3 |
    double D = 2.0 * ((x1 - x3) * (y2 - y3) - (x2 - x3) * (y1 - y3));
    
    // D接近0说明三点共线
    if (std::abs(D) < 1e-10) {
        return nullptr;  // 退化为直线
    }
    
    // 计算圆心
    double A1 = x1*x1 + y1*y1 - x3*x3 - y3*y3;
    double A2 = x2*x2 + y2*y2 - x3*x3 - y3*y3;
    
    double cx = (A1*(y2-y3) - A2*(y1-y3)) / D;
    double cy = (A2*(x1-x3) - A1*(x2-x3)) / D;
    
    double radius = std::sqrt((x1-cx)*(x1-cx) + (y1-cy)*(y1-cy));
    
    // 确定起止角度和方向
    double start_angle = std::atan2(y1 - cy, x1 - cx);
    double end_angle = std::atan2(y3 - cy, x3 - cx);
    
    // 通过中间点确定方向
    double mid_angle = std::atan2(y2 - cy, x2 - cx);
    ArcDirection direction = determineDirection(start_angle, mid_angle, end_angle);
    
    return std::make_unique<ArcSegment>(
        Eigen::Vector2d(cx, cy), radius, start_angle, end_angle, direction);
}
```

### 4.5.3 Dubins路径

Dubins路径是连接两个有向点的最短仅前进路径，由最多3段组成：

- **CSC (圆弧-直线-圆弧)**：LSL, LSR, RSL, RSR
- **CCC (圆弧-圆弧-圆弧)**：LRL, RLR

```cpp
std::unique_ptr<ArcSegment> ArcSegment::createDubins(
    const Pose2D& start, const Pose2D& goal, 
    double curvature, double step_size) {
    
    double turning_radius = 1.0 / curvature;
    
    // 转换到局部坐标系
    double dx = goal.x - start.x;
    double dy = goal.y - start.y;
    double d = std::sqrt(dx*dx + dy*dy) / turning_radius;
    double theta = std::atan2(dy, dx);
    double alpha = normalizeAngle(start.yaw - theta);
    double beta = normalizeAngle(goal.yaw - theta);
    
    // 尝试所有6种路径类型，选择最短的
    std::vector<ArcSubSegment> best_path;
    double best_length = std::numeric_limits<double>::max();
    
    // LSL, RSR, LSR, RSL, RLR, LRL
    tryDubinsLSL(d, alpha, beta, turning_radius, best_path, best_length);
    tryDubinsRSR(d, alpha, beta, turning_radius, best_path, best_length);
    // ... 其他类型
    
    if (best_path.empty()) return nullptr;
    
    return std::make_unique<ArcSegment>(start, best_path, curvature);
}
```

### 4.5.4 Reeds-Shepp路径

Reeds-Shepp路径允许前进和后退，共有48种可能的路径类型：

```cpp
std::unique_ptr<ArcSegment> ArcSegment::createReedsShepp(
    const Pose2D& start, const Pose2D& goal,
    double curvature, double step_size) {
    
    // 与Dubins类似，但允许倒车
    // 路径类型更多：C|C|C, C|CC, CC|C, CSC, C|C[PI/2]SC, ...
    
    std::vector<ArcSubSegment> best_path;
    double best_length = std::numeric_limits<double>::max();
    
    // 尝试所有可能的路径类型
    tryRSCCC(start, goal, curvature, best_path, best_length);
    tryRSCSC(start, goal, curvature, best_path, best_length);
    // ...
    
    if (best_path.empty()) return nullptr;
    
    return std::make_unique<ArcSegment>(start, best_path, curvature);
}
```

## 4.6 PathSegmentFactory 工厂类

### 4.6.1 使用工厂创建路径段

```cpp
class PathSegmentFactory {
public:
    using CreatorFunc = std::function<PathSegmentPtr(
        const Pose2D& start, const Pose2D& end,
        const MotionConstraints& constraints,
        const std::vector<Pose2D>& params)>;

    // 注册创建函数
    static void registerCreator(PathSegmentType type, CreatorFunc creator);
    
    // 创建路径段
    static PathSegmentPtr create(PathSegmentType type,
                                  const Pose2D& start, const Pose2D& end,
                                  const MotionConstraints& constraints,
                                  const std::vector<Pose2D>& params = {});

private:
    static std::map<PathSegmentType, CreatorFunc> creators_;
};
```

### 4.6.2 使用示例

```cpp
// 创建直线段
auto straight = PathSegmentFactory::create(
    PathSegmentType::kStraight,
    start, end, constraints);

// 创建贝塞尔曲线段
std::vector<Pose2D> ctrl_pts = {ctrl1, ctrl2};
auto bezier = PathSegmentFactory::create(
    PathSegmentType::kCubicBezier,
    start, end, constraints, ctrl_pts);

// 创建圆弧段（三点方式）
std::vector<Pose2D> mid_pt = {mid_point};
auto arc = PathSegmentFactory::create(
    PathSegmentType::kCircularArc,
    start, end, constraints, mid_pt);
```
