# 7. 状态机模块

本章详细介绍导航状态机的设计与实现。

## 7.1 模块概述

`NavigationStateMachine` 负责管理导航过程中的状态转换，确保状态转换的合法性和一致性。相比原代码中分散的状态判断逻辑，状态机提供了更清晰、更可维护的状态管理方式。

### 设计目标

- **集中管理**：所有状态转换逻辑集中在一处
- **合法性检查**：确保只有合法的状态转换才会执行
- **可观察性**：支持状态变化回调，便于调试和日志
- **可扩展性**：易于添加新状态和转换规则

## 7.2 状态定义

### 7.2.1 StateMachineState 枚举

```cpp
enum class StateMachineState {
    kIdle,           ///< 空闲状态 - 初始状态，等待启动
    kStartRotation,  ///< 起点旋转 - 调整初始航向
    kFollowingPath,  ///< 路径跟踪 - 执行路径跟踪
    kDecelerating,   ///< 减速中 - 因障碍物减速
    kPaused,         ///< 暂停 - 完全停止等待
    kEndRotation,    ///< 终点旋转 - 调整最终航向
    kCompleted,      ///< 已完成 - 导航成功结束
    kError           ///< 错误状态 - 发生错误
};
```

### 7.2.2 状态说明

| 状态 | 描述 | 典型行为 |
|-----|------|---------|
| kIdle | 空闲，等待初始化 | 无输出 |
| kStartRotation | 起点原地旋转 | 输出角速度 |
| kFollowingPath | 路径跟踪中 | 输出线速度+角速度 |
| kDecelerating | 障碍物减速 | 逐渐减小速度 |
| kPaused | 完全暂停 | 零速度 |
| kEndRotation | 终点原地旋转 | 输出角速度 |
| kCompleted | 导航完成 | 零速度 |
| kError | 错误状态 | 零速度 |

## 7.3 事件定义

### 7.3.1 StateMachineEvent 枚举

```cpp
enum class StateMachineEvent {
    kStart,              ///< 开始导航
    kRotationComplete,   ///< 旋转完成
    kSegmentComplete,    ///< 路径段完成
    kPathComplete,       ///< 整条路径完成
    kObstacleDetected,   ///< 检测到障碍物
    kObstacleCleared,    ///< 障碍物消除
    kEmergencyStop,      ///< 紧急停止
    kResume,             ///< 恢复导航
    kCancel,             ///< 取消导航
    kError               ///< 发生错误
};
```

### 7.3.2 事件说明

| 事件 | 触发条件 | 预期行为 |
|-----|---------|---------|
| kStart | 调用initialize后 | 进入StartRotation或FollowingPath |
| kRotationComplete | 角度误差小于阈值 | 进入下一状态 |
| kSegmentComplete | 到达段终点 | 继续下一段或进入EndRotation |
| kPathComplete | 完成所有路径段 | 进入EndRotation或Completed |
| kObstacleDetected | 检测到障碍物 | 进入Decelerating |
| kObstacleCleared | 障碍物消除 | 恢复FollowingPath |
| kEmergencyStop | 急停按钮触发 | 进入Paused |
| kResume | 恢复按钮触发 | 恢复FollowingPath |
| kCancel | 取消导航 | 进入Completed |
| kError | 发生错误 | 进入Error |

## 7.5 类实现

### 7.5.1 类定义

```cpp
class NavigationStateMachine {
public:
    using StateChangeCallback = std::function<void(StateMachineState, StateMachineState)>;

    NavigationStateMachine();

    bool processEvent(StateMachineEvent event);
    StateMachineState getCurrentState() const;
    static std::string getStateName(StateMachineState state);
    static std::string getEventName(StateMachineEvent event);
    
    void setStateChangeCallback(StateChangeCallback callback);
    void setNeedStartRotation(bool need);
    void setNeedEndRotation(bool need);
    bool needStartRotation() const;
    bool needEndRotation() const;
    
    void reset();
    bool isActive() const;
    bool isCompleted() const;
    bool hasError() const;

private:
    void transitionTo(StateMachineState new_state);
    bool isValidTransition(StateMachineState from, StateMachineState to) const;

    StateMachineState current_state_;
    StateChangeCallback state_change_callback_;
    bool need_start_rotation_{false};
    bool need_end_rotation_{false};
};
```

### 7.5.2 事件处理

```cpp
bool NavigationStateMachine::processEvent(StateMachineEvent event) {
    StateMachineState new_state = current_state_;
    
    switch (current_state_) {
        case StateMachineState::kIdle:
            if (event == StateMachineEvent::kStart) {
                new_state = need_start_rotation_ ? 
                    StateMachineState::kStartRotation : 
                    StateMachineState::kFollowingPath;
            }
            break;
            
        case StateMachineState::kStartRotation:
            if (event == StateMachineEvent::kRotationComplete) {
                new_state = StateMachineState::kFollowingPath;
            } else if (event == StateMachineEvent::kObstacleDetected) {
                new_state = StateMachineState::kDecelerating;
            }
            break;
            
        case StateMachineState::kFollowingPath:
            if (event == StateMachineEvent::kSegmentComplete) {
                // 保持在FollowingPath，继续下一段
                new_state = StateMachineState::kFollowingPath;
            } else if (event == StateMachineEvent::kPathComplete) {
                new_state = need_end_rotation_ ? 
                    StateMachineState::kEndRotation : 
                    StateMachineState::kCompleted;
            } else if (event == StateMachineEvent::kObstacleDetected) {
                new_state = StateMachineState::kDecelerating;
            }
            break;
            
        case StateMachineState::kDecelerating:
            // 减速到零后自动进入Paused
            // 这个转换在外部检测速度后触发
            if (event == StateMachineEvent::kObstacleCleared) {
                new_state = StateMachineState::kFollowingPath;
            }
            break;
            
        case StateMachineState::kPaused:
            if (event == StateMachineEvent::kObstacleCleared ||
                event == StateMachineEvent::kResume) {
                new_state = StateMachineState::kFollowingPath;
            }
            break;
            
        case StateMachineState::kEndRotation:
            if (event == StateMachineEvent::kRotationComplete) {
                new_state = StateMachineState::kCompleted;
            }
            break;
            
        default:
            break;
    }
    
    // 全局事件处理
    if (event == StateMachineEvent::kCancel) {
        new_state = StateMachineState::kCompleted;
    } else if (event == StateMachineEvent::kError) {
        new_state = StateMachineState::kError;
    } else if (event == StateMachineEvent::kEmergencyStop) {
        new_state = StateMachineState::kPaused;
    }
    
    // 执行转换
    if (new_state != current_state_) {
        if (isValidTransition(current_state_, new_state)) {
            transitionTo(new_state);
            return true;
        }
    }
    
    return false;
}
```

### 7.5.3 状态转换

```cpp
void NavigationStateMachine::transitionTo(StateMachineState new_state) {
    StateMachineState old_state = current_state_;
    current_state_ = new_state;
    
    // 触发回调
    if (state_change_callback_) {
        state_change_callback_(old_state, new_state);
    }
}
```

### 7.5.4 转换合法性检查

```cpp
bool NavigationStateMachine::isValidTransition(StateMachineState from, 
                                                StateMachineState to) const {
    // Error和Completed是终态，只能被特定事件改变
    if (from == StateMachineState::kError) {
        return false;  // Error状态无法转出（除非reset）
    }
    
    if (from == StateMachineState::kCompleted) {
        return false;  // Completed状态无法转出（除非reset）
    }
    
    // 不允许回退到Idle
    if (to == StateMachineState::kIdle && from != StateMachineState::kIdle) {
        return false;
    }
    
    return true;
}
```

## 7.6 使用示例

### 7.6.1 基本使用

```cpp
NavigationStateMachine state_machine;

// 设置回调
state_machine.setStateChangeCallback(
    [](StateMachineState old_state, StateMachineState new_state) {
        std::cout << "State: " 
                  << NavigationStateMachine::getStateName(old_state)
                  << " -> "
                  << NavigationStateMachine::getStateName(new_state)
                  << std::endl;
    });

// 配置
state_machine.setNeedStartRotation(true);
state_machine.setNeedEndRotation(true);

// 启动
state_machine.processEvent(StateMachineEvent::kStart);
// 输出: State: Idle -> StartRotation

// 旋转完成
state_machine.processEvent(StateMachineEvent::kRotationComplete);
// 输出: State: StartRotation -> FollowingPath

// 检测到障碍物
state_machine.processEvent(StateMachineEvent::kObstacleDetected);
// 输出: State: FollowingPath -> Decelerating

// 障碍物消除
state_machine.processEvent(StateMachineEvent::kObstacleCleared);
// 输出: State: Decelerating -> FollowingPath

// 路径完成
state_machine.processEvent(StateMachineEvent::kPathComplete);
// 输出: State: FollowingPath -> EndRotation

// 终点旋转完成
state_machine.processEvent(StateMachineEvent::kRotationComplete);
// 输出: State: EndRotation -> Completed
```

### 7.6.2 在NavigationExecutor中的集成

```cpp
// NavigationExecutor::execute() 中的使用
NavigationOutput NavigationExecutor::execute(...) {
    NavigationOutput output;
    
    // 根据状态执行不同逻辑
    switch (state_machine_.getCurrentState()) {
        case StateMachineState::kStartRotation:
            output = handleStartRotation(current_pose, ...);
            break;
            
        case StateMachineState::kFollowingPath:
            output = handlePathFollowing(current_pose, ...);
            break;
            
        case StateMachineState::kEndRotation:
            output = handleEndRotation(current_pose, ...);
            break;
            
        case StateMachineState::kDecelerating:
            output.velocity = decelerateStop(...);
            output.status = NavigationStatus::kObstaclePaused;
            break;
            
        case StateMachineState::kPaused:
            output.velocity = Velocity(0, 0, 0);
            output.status = NavigationStatus::kObstaclePaused;
            break;
            
        case StateMachineState::kCompleted:
            output.velocity = Velocity(0, 0, 0);
            output.status = NavigationStatus::kGoalReached;
            break;
            
        case StateMachineState::kError:
            output.velocity = Velocity(0, 0, 0);
            output.status = NavigationStatus::kError;
            break;
            
        default:
            break;
    }
    
    return output;
}
```

## 7.7 状态机优势

### 7.7.1 与原代码对比

**原代码（分散的状态判断）**：
```cpp
// 分散在各处的标志位
bool is_rotating_;
bool is_decelerating_;
bool is_completed_;
bool has_error_;
int current_phase_;  // 0=准备, 1=执行, 2=结束

// 复杂的条件判断
if (!is_completed_ && !has_error_) {
    if (is_rotating_) {
        if (current_phase_ == 0) {
            // 起点旋转
        } else if (current_phase_ == 2) {
            // 终点旋转
        }
    } else if (is_decelerating_) {
        // 减速逻辑
    } else {
        // 正常跟踪
    }
}
```

**重构后（状态机）**：
```cpp
switch (state_machine_.getCurrentState()) {
    case StateMachineState::kStartRotation:
        return handleStartRotation(...);
    case StateMachineState::kFollowingPath:
        return handlePathFollowing(...);
    case StateMachineState::kEndRotation:
        return handleEndRotation(...);
    // ...
}
```

### 7.7.2 优势总结

| 方面 | 原代码 | 状态机 |
|-----|-------|-------|
| 可读性 | 差，需要理解多个标志位组合 | 好，状态明确 |
| 可维护性 | 差，修改易引入bug | 好，转换规则清晰 |
| 可扩展性 | 差，新增状态需要修改多处 | 好，只需添加状态和转换 |
| 调试 | 困难，状态难以追踪 | 容易，有回调和日志 |
| 正确性 | 难以保证状态一致性 | 转换合法性检查 |
