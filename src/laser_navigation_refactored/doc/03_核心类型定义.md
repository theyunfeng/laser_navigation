# 3. 核心类型定义

本章详细介绍 `core/types.hpp` 中定义的所有基础数据类型。

## 3.1 底盘类型枚举

### ChassisType

底盘类型在节点启动时从 `model.json` 配置文件中读取，而非每次导航任务指定。

```cpp
enum class ChassisType {
    kDifferential,      ///< 差速底盘 - DiffDrive (vx, ω)
    kSwerve4WIS4WID     ///< 四转四驱底盘 - 4WIS4WID (vx, vy, ω)
};
```

### model.json 配置示例

```json
{
    "agvType": "4WIS4WID"
}
```

### 底盘类型对照表

| 枚举值 | model.json 中的 agvType | 描述 | 速度输出 |
|-------|------------------------|------|---------|
| `kDifferential` | `DiffDrive` | 双轮差速底盘，不支持横向移动 | (vx, ω) |
| `kSwerve4WIS4WID` | `4WIS4WID` | 四转四驱底盘，支持全向移动 | (vx, vy, ω) |

**使用示例**：
```cpp
// 从 model.json 读取底盘类型
JsonParser parser;
ChassisType chassis_type = parser.parseModelConfig("model.json");

// 设置到导航配置中
NavigationConfig config;
config.chassis_type = chassis_type;
```

## 3.2 基础几何类型

### 3.2.1 Pose2D - 2D位姿

```cpp
struct Pose2D {
    double x{0.0};        ///< x坐标 (m)
    double y{0.0};        ///< y坐标 (m)
    double yaw{0.0};      ///< 航向角 (rad)
    std::string node_id;  ///< 节点ID（可选）
    
    // 构造函数
    Pose2D() = default;
    Pose2D(double x_, double y_, double yaw_ = 0.0, const std::string& id = "");
    
    // 工具方法
    Eigen::Vector2d toVector() const;           // 转换为Eigen向量
    double distanceTo(const Pose2D& other) const;  // 计算距离
    double angleTo(const Pose2D& other) const;     // 计算方位角
};
```

**成员说明**：

| 成员 | 类型 | 描述 | 单位 |
|-----|------|------|-----|
| x | double | X坐标 | m |
| y | double | Y坐标 | m |
| yaw | double | 航向角（相对X轴正向逆时针） | rad |
| node_id | string | 节点标识符（可选） | - |

**使用示例**：
```cpp
Pose2D start(0.0, 0.0, 0.0);
Pose2D goal(5.0, 3.0, M_PI/2);

double dist = start.distanceTo(goal);  // 计算欧氏距离
double angle = start.angleTo(goal);    // 计算方位角
```

struct Point2D {

### 3.2.3 Velocity - 速度指令

```cpp
struct Velocity {
    double linear_x{0.0};   ///< x方向线速度 (m/s)，车体前向
    double linear_y{0.0};   ///< y方向线速度 (m/s)，车体左向（仅四转四驱使用）
    double angular{0.0};    ///< 角速度 (rad/s)
    
    // 构造函数
    Velocity();                          // 默认构造
    Velocity(double vx, double w);       // 差速底盘
    Velocity(double vx, double vy, double w);  // 四转四驱
    
    // 工具方法
    bool isZero(double eps = 1e-6) const;   // 判断是否接近零
    void reset();                            // 归零
    double linearMagnitude() const;          // 合成线速度大小
    double linearDirection() const;          // 线速度方向
};
```

**速度说明**：

| 成员 | 差速底盘 | 四转四驱 | 单位 |
|-----|---------|---------|-----|
| linear_x | 前进速度 | 前进速度 | m/s |
| linear_y | 始终为0 | 横向速度 | m/s |
| angular | 角速度 | 角速度 | rad/s |

**使用示例**：
```cpp
// 差速底盘速度
Velocity diff_vel(0.5, 0.1);  // vx=0.5m/s, ω=0.1rad/s

// 四转四驱速度
Velocity swerve_vel(0.5, 0.2, 0.1);  // vx=0.5, vy=0.2, ω=0.1

// 检查速度
if (vel.isZero()) {
    // 车辆静止
}
```

## 3.3 里程计反馈

### OdometryFeedback

```cpp
struct OdometryFeedback {
    Pose2D pose;              ///< 当前位姿
    Velocity velocity;        ///< 当前车体速度
    double timestamp{0.0};    ///< 时间戳 (s)
    bool is_valid{false};     ///< 数据是否有效
    double timeout{0.2};      ///< 超时阈值 (s)
    
    // 方法
    bool isExpired(double current_time) const;  // 检查是否过期
    void update(const Pose2D& p, const Velocity& v, double ts);
    void invalidate();
};
```

**用途**：
- 提供给速度规划器作为当前速度参考
- 提供给LQR控制器作为速度前馈
- 用于急停恢复时的位置偏移检测

## 3.4 运动约束参数

### MotionConstraints

```cpp
struct MotionConstraints {
    // 线速度约束
    double max_velocity{0.5};         ///< 最大线速度 (m/s)
    double max_acceleration{0.3};     ///< 最大加速度 (m/s²)
    double max_deceleration{0.5};     ///< 最大减速度 (m/s²)
    double max_jerk{1.0};             ///< 最大加加速度 (m/s³)
    
    // 角速度约束
    double max_angular_velocity{0.5};       ///< 最大角速度 (rad/s)
    double max_angular_acceleration{0.5};   ///< 最大角加速度 (rad/s²)
    double max_angular_deceleration{0.8};   ///< 最大角减速度 (rad/s²)
    double max_angular_jerk{2.0};           ///< 最大角加加速度 (rad/s³)
    
    // 到达判定
    double reach_distance{0.05};      ///< 到达距离阈值 (m)
    double reach_angle{0.01};         ///< 到达角度阈值 (rad)
    
    // 运动方向
    bool is_forward{true};            ///< 是否前进
};
```

**参数表**：

| 参数 | 默认值 | 描述 | 单位 |
|-----|-------|------|-----|
| max_velocity | 0.5 | 最大线速度 | m/s |
| max_acceleration | 0.3 | 最大线加速度 | m/s² |
| max_deceleration | 0.5 | 最大线减速度 | m/s² |
| max_jerk | 1.0 | 最大线加加速度 | m/s³ |
| max_angular_velocity | 0.5 | 最大角速度 | rad/s |
| max_angular_acceleration | 0.5 | 最大角加速度 | rad/s² |
| max_angular_deceleration | 0.8 | 最大角减速度 | rad/s² |
| max_angular_jerk | 2.0 | 最大角加加速度 | rad/s³ |
| reach_distance | 0.05 | 到达距离阈值 | m |
| reach_angle | 0.01 | 到达角度阈值 | rad |
| is_forward | true | 行驶方向 | - |

## 3.8 LQR控制器参数

### LQRParams (直线LQR)

```cpp
struct LQRParams {
    std::vector<double> q{10.0, 10.0, 1.0};  ///< 状态权重 [x, y, theta]
    std::vector<double> r{1.0, 1.0};         ///< 输入权重 [v, omega]
    double dt{0.04};                          ///< 控制周期 (s)
    int max_iterations{150};                  ///< DARE迭代次数
    double tolerance{1e-6};                   ///< 收敛容差
};
```

### BezierLQRParams (贝塞尔LQR)

struct BezierLQRParams {
