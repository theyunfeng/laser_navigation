# 5. 速度规划器

本章详细介绍S曲线速度规划器的原理和实现。

## 5.1 模块概述

`SCurvePlanner` 实现了7段式S曲线速度规划，提供平滑的加减速控制，避免速度突变导致的机械冲击。

### 设计目标

- **平滑性**：加速度连续变化，减少机械冲击
- **效率**：在满足约束条件下尽快达到目标速度
- **灵活性**：支持线速度和角速度规划
- **可配置**：支持自定义加速度、减速度、加加速度限制

## 5.2 S曲线原理

### 5.2.1 7段式S曲线

完整的S曲线速度规划包含7个阶段：

```
速度 v
  ▲
  │            T4 匀速段
  │         ┌─────────┐
  │        /           \
  │   T2  /             \  T6
  │  ┌───┘               └───┐
  │ /  T3               T5   \
  │/ T1                   T7  \
  ├────────────────────────────▶ 时间 t
  0

加速度 a
  ▲
  │  ┌───┐ T2
  │ /     \
  │/ T1    \ T3
  ├──────────────────────────────▶ t
  │         T4         / T5
  │              \    /
  │          T7   └──┘ T6
  ▼
```

| 阶段 | 名称 | 加速度变化 | 加加速度 |
|-----|------|-----------|---------|
| T1 | 加加速段 | 0 → max_acc | jerk > 0 |
| T2 | 匀加速段 | max_acc | jerk = 0 |
| T3 | 减加速段 | max_acc → 0 | jerk < 0 |
| T4 | 匀速段 | 0 | jerk = 0 |
| T5 | 加减速段 | 0 → -max_dec | jerk < 0 |
| T6 | 匀减速段 | -max_dec | jerk = 0 |
| T7 | 减减速段 | -max_dec → 0 | jerk > 0 |

### 5.2.2 数学公式

**加加速段 (T1)**：
$$a(t) = j \cdot t$$
$$v(t) = v_0 + \frac{1}{2} j \cdot t^2$$
$$s(t) = v_0 \cdot t + \frac{1}{6} j \cdot t^3$$

**匀加速段 (T2)**：
$$a(t) = a_{max}$$
$$v(t) = v_1 + a_{max} \cdot t$$
$$s(t) = v_1 \cdot t + \frac{1}{2} a_{max} \cdot t^2$$

其中 $j$ 为加加速度，$v_0$ 为初始速度，$v_1$ 为T1结束时的速度。

## 5.4 初始化流程

### 5.4.1 线性运动初始化

```cpp
void SCurvePlanner::initializeLinear(double total_distance, 
                                      double initial_velocity,
                                      const MotionConstraints& constraints) {
    constraints_ = constraints;
    total_distance_ = total_distance;
    initial_velocity_ = initial_velocity;
    current_velocity_ = initial_velocity;
    current_acceleration_ = 0.0;
    is_in_final_decel_ = false;
    
    // 计算各阶段时间参数
    computeTimeParameters();
    
    is_initialized_ = true;
}
```

### 5.4.2 时间参数计算

```cpp
void SCurvePlanner::computeTimeParameters() {
    double v_max = constraints_.max_velocity;
    double a_max = constraints_.max_acceleration;
    double d_max = constraints_.max_deceleration;
    double j_max = constraints_.max_jerk;
    
    // 计算加速段所需距离
    // 从 v0 加速到 v_max 的距离
    double t_acc = (v_max - initial_velocity_) / a_max;  // 简化计算
    double s_acc = initial_velocity_ * t_acc + 0.5 * a_max * t_acc * t_acc;
    
    // 计算减速段所需距离
    // 从 v_max 减速到 target_end_velocity_
    double t_dec = (v_max - target_end_velocity_) / d_max;
    double s_dec = v_max * t_dec - 0.5 * d_max * t_dec * t_dec;
    
    // 判断是否为三角形速度曲线（无匀速段）
    if (s_acc + s_dec > total_distance_) {
        // 三角形曲线：需要计算实际能达到的最大速度
        // v_peak^2 = v0^2 + 2*a*(s_acc_actual)
        // v_peak^2 = v_end^2 + 2*d*(s_dec_actual)
        // s_acc_actual + s_dec_actual = total_distance
        params_.is_triangular = true;
    } else {
        params_.is_triangular = false;
        params_.cruise_distance = total_distance_ - s_acc - s_dec;
    }
    
    params_.acceleration_distance = s_acc;
    params_.deceleration_distance = s_dec;
}
```

## 5.5 速度计算

### 5.5.1 主计算函数

```cpp
double SCurvePlanner::computeVelocity(double remaining_distance, double dt) {
    if (!is_initialized_) return 0.0;
    
    double v_max = constraints_.max_velocity;
    double a_max = constraints_.max_acceleration;
    double d_max = constraints_.max_deceleration;
    
    // 计算需要开始减速的距离
    double v_current = current_velocity_;
    double v_end = target_end_velocity_;
    
    // 减速所需距离: s = (v^2 - v_end^2) / (2*d)
    double decel_distance = (v_current * v_current - v_end * v_end) / (2.0 * d_max);
    
    double target_velocity;
    
    if (remaining_distance <= decel_distance * 1.1) {  // 1.1倍余量
        // 减速阶段
        target_velocity = computeDecelerationPhase(remaining_distance, dt);
    } else if (current_velocity_ < v_max) {
        // 加速阶段
        target_velocity = computeAccelerationPhase(dt);
    } else {
        // 匀速阶段
        target_velocity = v_max;
    }
    
    // 限幅
    target_velocity = std::max(v_end, std::min(v_max, target_velocity));
    current_velocity_ = target_velocity;
    
    return target_velocity * (constraints_.is_forward ? 1.0 : -1.0);
}
```

### 5.5.2 加速阶段

```cpp
double SCurvePlanner::computeAccelerationPhase(double dt) {
    double a_max = constraints_.max_acceleration;
    double j_max = constraints_.max_jerk;
    double v_max = constraints_.max_velocity;
    
    // S曲线加速：加速度逐渐增加
    if (current_acceleration_ < a_max) {
        current_acceleration_ += j_max * dt;
        current_acceleration_ = std::min(current_acceleration_, a_max);
    }
    
    // 接近目标速度时，加速度逐渐减小
    double v_remaining = v_max - current_velocity_;
    double a_limit = std::sqrt(2.0 * j_max * v_remaining);
    current_acceleration_ = std::min(current_acceleration_, a_limit);
    
    return current_velocity_ + current_acceleration_ * dt;
}
```

### 5.5.3 减速阶段

```cpp
double SCurvePlanner::computeDecelerationPhase(double remaining_distance, double dt) {
    double d_max = constraints_.max_deceleration;
    double v_end = target_end_velocity_;
    
    // 根据剩余距离计算期望速度
    // v^2 = v_end^2 + 2*d*s
    double v_from_distance = std::sqrt(v_end * v_end + 2.0 * d_max * remaining_distance);
    
    // 根据时间递推计算速度
    // v = v_current - d*dt
    double v_from_time = current_velocity_ - d_max * dt;
    
    // 取较小值确保能停下
    double target_velocity = std::min(v_from_distance, 
                                       std::max(v_end, v_from_time));
    
    // 更新加速度（负值表示减速）
    current_acceleration_ = (target_velocity - current_velocity_) / dt;
    
    return target_velocity;
}
```

## 5.6 角速度规划

角速度规划与线速度规划类似，但使用角度相关的约束参数：

```cpp
void SCurvePlanner::initializeRotation(double total_angle, 
                                        double initial_angular_velocity,
                                        const MotionConstraints& constraints) {
    // 使用角速度约束
    constraints_.max_velocity = constraints.max_angular_velocity;
    constraints_.max_acceleration = constraints.max_angular_acceleration;
    constraints_.max_deceleration = constraints.max_angular_deceleration;
    constraints_.max_jerk = constraints.max_angular_jerk;
    
    total_distance_ = total_angle;  // 用角度代替距离
    initial_velocity_ = initial_angular_velocity;
    current_velocity_ = initial_angular_velocity;
    current_acceleration_ = 0.0;
    
    computeTimeParameters();
    is_initialized_ = true;
}

double SCurvePlanner::computeAngularVelocity(double remaining_angle, double dt) {
    // 与computeVelocity相同的逻辑
    return computeVelocity(remaining_angle, dt);
}
```

## 5.7 热更新支持

当路径被热更新时，需要从当前速度继续规划：

```cpp
void SCurvePlanner::updatePath(double remaining_distance, 
                                double current_velocity,
                                const MotionConstraints& constraints) {
    constraints_ = constraints;
    total_distance_ = remaining_distance;
    
    // 继承当前速度，而不是从0开始
    initial_velocity_ = current_velocity;
    current_velocity_ = current_velocity;
    
    // 重新计算参数
    computeTimeParameters();
    
    is_initialized_ = true;
}
```

## 5.8 使用示例

### 5.8.1 直线段规划

```cpp
SCurvePlanner linear_planner;

// 初始化
MotionConstraints constraints;
constraints.max_velocity = 0.5;        // 0.5 m/s
constraints.max_acceleration = 0.3;   // 0.3 m/s²
constraints.max_deceleration = 0.5;   // 0.5 m/s²
constraints.max_jerk = 1.0;           // 1.0 m/s³

linear_planner.initializeLinear(10.0, 0.0, constraints);  // 10m, 从0开始

// 控制循环
while (remaining_distance > reach_threshold) {
    double planned_velocity = linear_planner.computeVelocity(remaining_distance, 0.04);
    // 使用 planned_velocity ...
}
```

### 5.8.2 旋转规划

```cpp
SCurvePlanner rotation_planner;

// 初始化旋转
MotionConstraints constraints;
constraints.max_angular_velocity = 0.5;       // 0.5 rad/s
constraints.max_angular_acceleration = 0.5;  // 0.5 rad/s²
constraints.max_angular_deceleration = 0.8;  // 0.8 rad/s²
constraints.max_angular_jerk = 2.0;          // 2.0 rad/s³

double angle_to_rotate = 1.57;  // 90度
rotation_planner.initializeRotation(angle_to_rotate, 0.0, constraints);

// 控制循环
while (remaining_angle > reach_angle_threshold) {
    double planned_omega = rotation_planner.computeAngularVelocity(remaining_angle, 0.04);
    // 使用 planned_omega ...
}
```
