# 1. 项目概述

## 1.1 项目简介

`laser_navigation_refactored` 是一个 ROS2 导航控制功能包，基于原有的 `laser_navigation_package` 重构而来。该包实现了完整的路径跟踪导航功能，支持多种轨迹类型和底盘类型。

### 主要功能

- **多轨迹类型支持**：直线、三次贝塞尔曲线、圆弧、Dubins路径、Reeds-Shepp路径
- **多底盘支持**：差速底盘 (Differential) 和四转四驱底盘 (4WIS4WID)
- **S曲线速度规划**：7段式S曲线实现平滑加减速
- **LQR轨迹跟踪**：基于LQR的高精度路径跟踪控制
- **状态机管理**：完整的导航状态管理
- **JSON配置接口**：与调度系统的标准JSON接口
- **热更新支持**：运行时动态追加路径点
- **急停恢复机制**：障碍物停止后的智能恢复策略

## 1.2 功能特性

### 轨迹类型

| 轨迹类型 | 描述 | 适用场景 |
|---------|------|---------|
| Straight | 直线轨迹 | 长距离直行 |
| CubicBezier | 三次贝塞尔曲线 | 平滑转弯、S形路径 |
| Arc/Circular | 圆弧轨迹 | 定点转弯 |
| Dubins | Dubins路径 | 最短前进路径 |
| ReedsShepp | Reeds-Shepp路径 | 支持倒车的最短路径 |

### 底盘支持

| 底盘类型 | 输出 | 特点 |
|---------|------|------|
| Differential | (vx, ω) | 传统差速底盘 |
| Swerve4WIS4WID | (vx, vy, ω) | 四转四驱，支持横向移动 |

## 1.3 与原包的对应关系

| 原包文件 | 重构后模块 | 说明 |
|---------|-----------|------|
| correct.h/cpp | NavigationExecutor | 核心导航执行器 |
| straight.h/cpp | StraightSegment + StraightLQRController | 直线段和控制 |
| bezier.h/cpp | BezierSegment + BezierLQRController | 贝塞尔曲线段和控制 |
| srotate.h/cpp | SCurvePlanner (rotation) | 旋转速度规划 |
| configHelper.h/cpp | JsonParser | JSON解析 |
| 分散的状态判断 | NavigationStateMachine | 状态机统一管理 |

## 1.6 快速开始

### 基本使用流程

```cpp
#include "laser_navigation_refactored/navigation_executor.hpp"
#include "laser_navigation_refactored/utils/json_parser.hpp"

// 1. 创建导航执行器
laser_navigation::NavigationExecutor navigator;
laser_navigation::JsonParser parser;

// 2. 解析JSON任务
auto task = parser.parseTask(json_string);

// 3. 初始化导航
NavigationConfig config;
config.waypoints = task->waypoints;
config.constraints = task->constraints;
config.segment_types = task->segment_types;
config.control_points = task->control_points;
config.chassis_type = task->chassis_type;

navigator.initialize(config, lqr_params, bezier_lqr_params);

// 4. 控制循环
while (navigating) {
    auto output = navigator.execute(current_pose, obstacle_stop, 
                                    obstacle_decel, cancel);
    publish_velocity(output.velocity);
    
    if (output.status == NavigationStatus::kGoalReached) {
        break;
    }
}
```
